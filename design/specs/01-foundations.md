# 01 · 设计基础规范（Design Foundations）

适用版本：迭代 1（iOS / Android，Flutter 3.x，Material 3）
设计基准：**390 × 844 pt（iPhone 14/15）**，Android 以 360 × 800 dp 等比适配。
网格：**4pt 基础网格**，间距与尺寸取值全部是 4 的倍数；常用间距限定为 **4 / 8 / 12 / 16 / 24 / 32 / 40**。

> 本文件是唯一 token 来源。所有页面标注、原型、Flutter 主题都引用这里的变量名，不另造颜色和字号。

---

## 1. 品牌与视觉方向

- 关键词：**专业、可靠、轻盈、户外**。马拉松训练工具，不做健身房的「能量感」视觉。
- 主色取「深海蓝」，代表配速、数据与可靠；强调色取「海鹦喙橙」，只用于**开始跑步、个人纪录、关键提醒**，占比不超过全屏 10%。
- 大面积留白 + 单一主 CTA。跑步中界面切换到**恒暗「运动模式」**：黑底白字、超大数字，保证强光下可读并降低 OLED 耗电。
- 不用拟物插画、不用渐变大背景、不用多色卡片堆叠。地图是唯一允许出现复杂纹理的区域。

## 2. 色彩

### 2.1 品牌色（Brand）

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `brand/600` | `#1463E6` | `#6FA6FF` | 主按钮、选中态、链接、进度 |
| `brand/500` | `#2A78F5` | `#8ABAFF` | 悬停/按压前的强调面 |
| `brand/100` | `#D6E4FD` | `#1E3A66` | 选中背景、标签底 |
| `brand/50` | `#EAF1FE` | `#132943` | 信息卡背景、选中行背景 |
| `accent/600` | `#E85D0B` | `#FF8A3D` | 开始跑步 CTA、PB 徽标、关键提醒 |
| `accent/100` | `#FFE7D6` | `#4A2A12` | 强调标签底色 |

> 主按钮在浅色下用 `brand/600` 底 + 白字（对比度 4.9:1）；`accent` 只做「开始跑步」与 PB，不用作普通链接。

### 2.6 地图样式

- 使用 `flutter_map` + 浅色地图瓦片（Carto Positron / 高德自定义浅色），不显示 POI 图标与路名密度过高图层。
- 轨迹线：宽 **6pt**，颜色 `brand/600`，圆角端点（round cap/join），下方 8pt、20% 透明度同色描边做发光。
- 起点标记：12pt 白心 + 3pt `success` 描边；终点：12pt 白心 + 3pt `accent/600` 描边。
- 跑步中地图上方统一加 `run/mapScrim` 渐变（顶部 96pt），保证状态栏与返回按钮可读。

## 3. 字体

### 3.1 字体族

| 平台 | 中文字体 | 数字字体 |
|---|---|---|
| iOS | PingFang SC | SF Pro / `.SFUI-Display`（系统） |
| Android | Noto Sans SC（备选 HarmonyOS Sans SC） | Roboto（系统） |
| Flutter 实现 | 不内嵌中文字体，使用系统默认 `fontFamilyFallback: ['PingFang SC','Noto Sans SC']` | 数字统一 `fontFeatures: [FontFeature.tabularFigures()]` |

数字规范：所有计时、里程、配速、心率必须**等宽数字（tabular）**，避免跳动；单位字号为主数字的 40%，与数字基线对齐，间距 4pt。

### 3.2 字阶（Light/Dark 共用，仅颜色不同）

| Token | 字号/行高 | 字重 | 字距 | 用途 |
|---|---|---|---|---|
| `display/xl` | 64 / 68 | 700 | -1.0 | 跑步中里程主数字 |
| `display/l` | 48 / 52 | 700 | -0.5 | 结果页核心数字 |
| `display/m` | 36 / 42 | 700 | -0.2 | 次要数字、分享卡 |
| `title/xl` | 28 / 34 | 700 | 0 | 页面大标题 |
| `title/l` | 22 / 28 | 600 | 0 | 卡片标题、结果页标题 |
| `title/m` | 18 / 24 | 600 | 0 | 区块标题、列表主文本 |
| `body/l` | 16 / 24 | 400 | 0.1 | 正文 |
| `body/m` | 14 / 22 | 400 | 0.1 | 说明、列表副文本 |
| `label/l` | 14 / 20 | 600 | 0.2 | 按钮、标签 |
| `caption` | 12 / 16 | 500 | 0.2 | 时间戳、单位说明 |
| `micro` | 11 / 14 | 500 | 0.3 | 图表刻度、角标 |

### 3.3 数字排版规则

- 配速格式 `5'32"`，里程 `10.42`（保留 2 位，单位「公里」独立成 14pt/secondary），时长 `01:02:33`（超过 1 小时才显示小时位）。
- 主数字与单位之间 4pt；数值不使用千分位。
- 负值/异常值统一显示 `--`，不得显示 `0.00` 或 `NaN`。

## 4. 间距与布局

| Token | 值 | 用途 |
|---|---|---|
| `space/1` | 4 | 图标与文字、数字与单位 |
| `space/2` | 8 | 标签内边距、紧凑列表 |
| `space/3` | 12 | 卡片内元素间距 |
| `space/4` | 16 | **页面左右边距**、卡片内边距 |
| `space/6` | 24 | 区块之间 |
| `space/8` | 32 | 大区块、结果页模块 |
| `space/10` | 40 | 空态上下留白 |

- 页面左右边距：**16**（全页面统一）；卡片圆角内边距 **16**。
- 列表项高度：单行 **56**，双行 **72**，带缩略图 **88**。
- 底部固定操作区：内容高 56 + 上下 padding 12，距安全区 ≥ 16；上方 1px `border/subtle` + `bg/surface` 背景。
- 最小点击区域 **48 × 48**；跑步中主控按钮直径 **76**（暂停/继续），结束按钮 56。

## 5. 圆角、描边、阴影

| Token | 值 | 用途 |
|---|---|---|
| `radius/xs` | 4 | 标签、小徽标 |
| `radius/sm` | 8 | 输入框、次级按钮 |
| `radius/md` | 12 | 列表卡、提示条 |
| `radius/lg` | 16 | **主卡片、主按钮** |
| `radius/xl` | 24 | 底部弹层、分享卡 |
| `radius/pill` | 999 | 状态胶囊、筛选 chip |
| `border/hairline` | 1pt | 分割线、卡片描边（用色 `border/subtle`） |

- 卡片默认**无阴影**，用 1pt 描边 + 白底区分层级；只有浮层/弹层使用阴影。
- 浮层阴影：`0 8 24 rgba(15,26,42,0.12)`；底部弹层：`0 -8 24 rgba(15,26,42,0.12)`。深色模式用 `0 8 24 rgba(0,0,0,0.5)`，不改圆角。

## 6. 图标

- 基础图标使用 **Material Symbols Rounded**，字重 400，光学尺寸 24；线性风格、圆角端点，禁止混用 Material Icons Filled 与 Cupertino 图标。
- 尺寸：列表/导航 **24**，区块标题 **20**，按钮内 **20**，紧凑标签 **16**，空态插画图标 **48**。
- 颜色：跟随文字色；激活态 `brand/600`；破坏性 `danger`。
- 自绘图标（需切图）：`ic_puffin_logo`（品牌标）、`ic_gps_satellite`（弱信号）、`ic_route_empty`（空轨迹）、`ic_share_card`（分享）。均为 24×24 viewBox 的 SVG，线宽 2，圆角端点，导出 @1x/@2x/@3x PNG（24/48/72）。
- 禁止用 emoji 当图标。

## 7. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 页面 push（右进） | 260ms | `easeOutCubic` |
| 底部弹层 | 240ms | `easeOutCubic` |
| 状态切换（暂停/继续） | 180ms | `easeInOut` |
| 数字变化 | 200ms 滚动 | `easeOut` |
| 骨架屏 shimmer | 1200ms 循环 | `linear` |
| GPS 信号跳动 | 600ms 脉冲 | `easeInOut` 循环 |

- 动效只用于状态反馈（暂停、同步、GPS 获取），不做装饰性动画。
- 跑步中数字每秒刷新，里程每 100m 更新一次，避免高频重绘。

## 8. 深浅色适配规则

1. 语义 token 成对提供（上表），开发只引用语义名，禁止在业务代码写死 hex。
2. 图片/地图/轨迹在深色下：地图瓦片切到深色样式（Carto Dark），轨迹线提亮到 `brand/500`，起点/终点标记保持白心。
3. 分享卡固定使用**深色品牌版**（`run/bg` 底），不随系统主题变化，保证导出图一致。
4. 跑步中界面恒暗（见 2.5），系统切浅色不改变。
5. 状态栏：浅色页面用深色图标，跑步中/分享卡用浅色图标；首页与「我的」顶部大标题滚动时状态栏保持透明。
6. 深色下不使用纯黑 `#000`，最低 `#0B1118`；不使用纯白大面积。

## 9. Flutter Token 落地

- 色彩/间距/圆角以 `ThemeExtension<AppTokens>` 提供，`MaterialApp` 同时注册 `light` 与 `dark` 两套；`themeMode: ThemeMode.system`。
- 字阶封装为 `AppTextStyles.of(context)`，内部按 `Theme.of(context).brightness` 取色。
- 运动模式单独一套 `RunTheme`（恒暗），跑步页用 `Theme(data: RunTheme.data)` 包裹，不污染全局主题。
- 参考实现见 `design/specs/app_theme.reference.dart`（可直接复制到 `lib/shared/theme/`，由 Frank 落地）。

## 10. 可访问性

- 支持系统字号放大到 **1.3×**：卡片高度自适应，数字区域允许换行，不裁切；跑步中数字最大 1.15×（避免溢出屏幕），其余页面不限。
- 所有图标按钮必须有 `Semantics(label)`；跑步中「暂停/结束」需支持屏幕朗读与触觉反馈。
- 触觉：开始跑步、暂停/继续、结束完成、同步成功用 `HapticFeedback.mediumImpact`；GPS 丢失用 `heavyImpact` 一次。
- 色盲安全：训练类型除颜色外必须带文字标签；GPS 状态除颜色外带信号格数与文字。
