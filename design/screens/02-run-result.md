## 2. 状态与异常

| 状态 | 表现 |
|---|---|
| 保存中 | 页面骨架：地图块 358×220 + 三列数字灰块 + 图表灰块；顶部居中「正在保存…」14/secondary；无底部分享按钮；保存完成后 200ms 淡入真实内容并 toast「完成！本次跑步已保存」 |
| 保存失败 | 顶部 `danger` banner 60 高（`cloud_off` +「记录已暂存在本地，联网后自动同步」+「重试」）；数据照常展示；分享按钮保留，分享卡右上角加「待同步」pill |
| 数据不足（< 0.1km 或 < 30s） | 不进入本页；返回来源页并 toast「跑步时间太短，未保存」 |
| 加载失败（打开历史记录详情） | 居中错误态：`error_outline` 48 `danger` +「记录加载失败」+ 说明「数据可能已损坏，请重试」+「重试」；AppBar 保留返回 |
| 无 GPS 轨迹（如手动导入缺轨迹） | 地图区替换为 `bg/sunken` + `route` 图标 48 +「本次记录没有轨迹数据」14/secondary；其余数据正常 |
| 轨迹信号缺失 | 缺失段虚线（2pt，50% 透明度）；地图右下角图例「— 信号缺失」11/secondary |
| 训练关联 | 副标题显示「已关联训练 · 轻松跑」；未关联且当天有任务：主数据下显示 info banner「关联到今日训练？」+「关联」Text；点击后展示任务选择弹层（今日任务，单选），成功后副标题更新 |
| 离线 | 顶部 `warning` banner「离线保存，联网后自动同步」；不高亮错误色 |

## 3. 配速曲线数据规则

- X 轴按**距离**等距，非时间；抽稀到 ≤ 120 个点后绘制。
- 每公里处画 4pt 白心圆点；起终点不画点。
- 配速异常（< 2'00" 或 > 15'00"）视为 GPS 跳点，剔除且不参与 Y 轴范围；剔除点导致曲线断段时用虚线。
- 最高/最低标注只在曲线两端各 1 个；无有效配速时整块替换为空态「本次配速数据不足」+ 说明。
- 深色模式下渐变透明度降至 8%，折线 `brand/500`。

## 4. 分享卡片（Share Card）

打开方式：底部弹层（高 85%），`bg/base`，顶部标题「分享跑步记录」18/600 + 关闭 44。

### 4.1 弹层内容

- 卡片预览：9:16 比例，宽 311（屏宽−64），高 553，`radius/xl`，深色品牌版（固定，不随主题）。
- 下方模板选择：3 个 44×44 圆形缩略图（深色轨迹版 / 数据版 / 纯色版），选中 2pt `brand/600` 描边；本迭代默认选「深色轨迹版」，其余两版作为同结构换底实现。
- 主按钮「保存图片」52；次按钮「分享到…」Text 48；均使用平台分享（`share_plus`）。
- 关闭：右上 ×；点击卡片外遮罩关闭。

## 6. Flutter 实现要点

| 模块 | 建议 |
|---|---|
| 轨迹渲染 | `flutter_map` 静态 `MapOptions(interactionOptions: none)` + `PolylineLayer` 分段着色；全屏页可交互 |
| 配速图 | `CustomPainter` 绘制（避免引入图表库），120 点以内；Y 轴反转（配速越小越快，图上越高） |
| 分段条 | `ListView` 嵌套禁用滚动（`shrinkWrap` + `NeverScrollableScrollPhysics`），外层滚动 |
| 分享卡 | `RepaintBoundary` + `toImage(pixelRatio: 3)` 导出 1080 宽；或 `screenshot` 包；导出前等待地图瓦片加载完成（`onMapReady` + 300ms） |
| 保存失败 | 结果数据先本地落库，`syncStatus` 字段区分 `synced/pending/failed`；重试仅重发 |
| 深色适配 | 页面跟随主题；分享卡与全屏轨迹固定深色 |

验收：所有数字格式正确；无心率数据显示 `--`；曲线/分段与轨迹一致；分享卡 1080×1440 可保存；保存失败数据不丢；训练关联状态可见。
