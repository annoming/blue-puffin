# 页面 01 · 跑步首页（Run Home）

文件：`design/screens/01-run-home.md` ｜ 原型：`design/prototype/index.html#run-home`
路由：`/run`（全屏，无底部导航）｜ 设计尺寸：390 × 844

覆盖状态：**空闲 / 定位中 / 跑步中 / 暂停 / 结束（保存中与失败）**，附加：GPS 弱信号、GPS 丢失、后台运行提示、权限拒绝、锁屏、退出确认。
视觉基调：**恒暗运动模式**（`run/*` token），不随系统深浅色变化。

## 2. 定位中（Acquiring）

- 地图中心：当前位置点外圈 56 脉冲（1.2s 循环，透明度 40% → 0）。
- 地图下方浮层（宽 358，高 72，`radius/lg`，`rgba(7,16,25,0.88)`，1pt `rgba(255,255,255,0.12)`，距左 16，距地图底 16）：
  - 上行：`location_searching` 20（旋转 1.2s）+「正在定位…」16/600 白色。
  - 下行：信号格 4 格（已获得格数按 accuracy）+「信号良好 / 较弱」12/500 `run/textSecondary`，距上 6。
- 主控：同位置，按钮变为「取消」（56 圆，`rgba(255,255,255,0.12)`，`close` 24 白色），下方文案「取消」。
- 30s 超时：浮层变 warning 色，文案「定位信号较弱，建议到开阔地带」，主控变 **76 圆 `accent/600`「仍然开始」**，其下 Text 按钮「取消」（44 高）。
- 定位失败（定位服务关闭）：浮层变为 `danger`「定位服务未开启」+ 说明「请在系统设置中开启定位服务」+「去设置」按钮（44 高，`danger` 底）。
- 此状态**不显示里程/计时**，杜绝 0.00 数字。

## 4. 暂停（Paused）

- 与跑步中同结构，差异：
  - 里程/时长/配速 颜色降为 `rgba(255,255,255,0.55)`；上方 12 处加 pill「已暂停」（22 高，`run/pause` 14% 底，文字 `run/pause` 12/600）。
  - 地图轨迹不变，当前位置点变空心（白描边 2pt）。
  - 主控：暂停按钮 → **继续**（76 圆 `accent/600`，`play_arrow` 28 白）；结束按钮保留。
  - 自动暂停时：暂停 pill 旁加说明「来电期间未计时」/「已切到后台」12/`run/textSecondary`，距 8。
- 点击继续：按钮 180ms loading（指示器），定位恢复后回到跑步中；定位未恢复时显示「正在恢复定位…」并保持暂停（最长 10s，之后允许带弱信号继续）。
- 暂停期间不累计时长，不记录轨迹点；暂停超过 30 分钟弹提示「已暂停 30 分钟，是否结束本次跑步？」（继续跑步 / 结束保存）。

## 5. 结束（Ending / Saved / Save Failed）

### 5.1 结束确认弹层（长按结束触发）

- 底部弹层：`radius/xl` 顶部，`bg/surface`（浅色页面仍用深色弹层？否——统一用 `run/bg` 深色弹层，保持运动模式），内边距 24。
- 标题「结束本次跑步？」22/600 白；说明「已跑 6.42 公里 · 38:12」14/`#9EB0C4`，距 8。
- 主按钮「结束并保存」52 高，`run/stop` 底白字；次按钮「继续跑步」52 高，`rgba(255,255,255,0.12)` 底白字，间距 12。
- 长按结束松手 → 弹层，不直接结束；弹层期间计时继续（极短），确认后停止。
- 若距离 < 0.1km 且时长 < 30s：直接「放弃本次跑步？」单按钮弹层，确认后 toast「跑步时间太短，未保存」，返回来源页。

### 5.2 保存中（结果页加载）

- 立即 `replace` 到结果页，结果页骨架：地图块 + 三列数字骨架 + 分段骨架；顶部居中 20pt 指示器 +「正在保存…」14/secondary。
- 保存成功后骨架替换为数据（200ms 淡入），顶部提示「完成！本次跑步已保存」3s 消失。

### 5.3 保存失败

- 结果页顶部 `danger` banner（高 60）：`cloud_off` 20 +「记录已暂存在本地，联网后自动同步」+ 右侧「重试」Text 按钮。
- 数字/轨迹仍展示（本地数据完整），分享按钮可用（分享卡标注「待同步」）。
- 退出结果页不丢数据；下次启动时自动重试。

| 丢失 | `danger` 底 `rgba(255,107,96,0.16)`、1pt 同色 40%、图标 `gps_off`、文字「GPS 信号丢失，正在重新定位…」 | 里程显示「—」，时长继续 |

## 7. 后台运行提示

### 7.1 Android 前台服务通知

- 标题：「步凡正在记录跑步」
- 内容：「6.42 公里 · 38:12 · 点击返回」
- 动作：「暂停」/「结束」
- 图标：品牌 puffin 单色 24。
- 通知常驻、不可滑动清除；结束跑步后自动移除。

### 7.2 回前台横幅

- 顶部安全区下 8，宽 358，高 44，`bg/surface` 96% + 阴影，图标 `directions_run` `brand/600`，文字「跑步记录中 · 6.42 公里」13/600 + 右侧「返回跑步」Text；3s 自动消失。
- 若后台期间自动暂停：文字改「已自动暂停 · 来电期间未计时」，右侧「继续」。

### 7.3 进程被杀恢复

重进 App 打开跑步页时，按草稿年龄分两种弹层。

**A. 草稿 ≤ 24h（可继续）**

- 底部弹层，遮罩 `rgba(4,10,16,.62)`，圆角 24 顶部：
  - 图标 `schedule` 20 / `run/pause`；标题「检测到未结束的跑步」22/600；
  - 说明「10/28 07:12 开始 · 已记录 6.42 公里 · 38:12」14/`run/textSecondary`；
  - 按钮自上而下：「继续记录」（主，`#FF6B1A`）、「保存并结束」（次，白色 12% 底）、「放弃记录」（Text 48，`run/stop`）；
  - 下滑或返回 = 暂时关闭弹层，草稿保留，下次进入再次提示。

**B. 草稿 > 24h（不可继续）**

- 同一弹层容器，顶部标题右侧加 `warning` 胶囊「超过 24 小时」：
  - 标题「检测到未结束的跑步」22/600；副标题「这次跑步无法继续」22/600（与标题二选一，保留副标题作为主文案）；
  - 说明「10/27 06:58 开始 · 已记录 8.12 公里 · 52:10」14/`run/textSecondary`；
  - 不可继续说明「超过 24 小时的记录无法继续，但可以保存已完成的数据。」13/`run/pause`，行高 20；
  - 按钮**仅两个**，自上而下固定顺序：
    1. 「保存并结束」— 主按钮 52，`#FF6B1A`；点击后进入保存中 → 结果页，数据以最后一次落库为准，缺失段落不补算；
    2. 「放弃记录」— Text 48，`run/stop`；点击先二次确认「放弃后无法恢复，确定放弃？」（主「放弃」danger、次「取消」），确认后删除本地草稿并回到空闲态。
  - **不提供「继续记录」**；下滑/返回不删除草稿，但每次都重新弹出本弹层，直到用户选择保存或放弃。
- 弹层出现时状态栏保持 `SystemUiOverlayStyle.light`，背景为模糊地图 + `run/mapScrim`，与跑步页一致。

## 8. 权限拒绝

### 8.1 定位权限

- 点击开始后系统弹窗被拒 → 页面内弹层：
  - 图标 `location_off` 40 `danger`；
  - 标题「需要定位权限」22/600；
  - 说明「开启后才能记录跑步轨迹、距离和配速」14/secondary；
  - 主「去设置」52、次「暂不」Text 48。
- 关闭弹层后回到空闲，主控仍可点（再次触发权限说明）；顶部常驻 `danger` banner「定位权限未开启」+「去设置」。
- 从设置返回：自动重新检查；已授权则 banner 消失，允许开始。

### 8.2 后台定位 / 通知

- 仅前台定位：跑步中 banner（见 §6）；不阻塞。
- 通知被关闭（Android）：跑步页一次性 info「通知已关闭，后台记录状态不可见」+「去设置」，可关闭。

## 9. 标注与实现要点（Flutter）

| 模块 | 建议实现 |
|---|---|
| 地图 | `flutter_map` + `MapController`；轨迹用 `PolylineLayer`（`strokeWidth: 6`）；当前位置 `MarkerLayer` + `AnimatedContainer` 脉冲 |
| 恒暗主题 | 页面根 `Theme(data: RunTheme.data, child: ...)`，状态栏 `SystemUiOverlayStyle.light` |
| 计时 | 单独 `Ticker`/`Timer.periodic(1s)`，仅重建数字子组件（`ValueListenableBuilder`），避免整页 setState |
| 长按结束 | `GestureDetector.onLongPressStart/End` + `AnimationController(800ms)` 画进度环；`HapticFeedback.mediumImpact` |
| 屏幕常亮 | `wakelock_plus`（需加入依赖，由 Frank 评估） |
| 后台 | `flutter_background_service`（已在依赖）+ Android 前台通知；iOS `location` background mode |
| 草稿 | Isar `run_draft` 表，每 3s 落库；启动时检查未结束草稿；`startedAt > 24h` 标记 `expired`，弹层只保留「保存并结束」「放弃记录」 |
| 性能 | 轨迹点抽稀（Douglas-Peucker，容差 3m）后再绘制；地图不随每秒计时重建 |

验收：6 个状态可独立进入；弱信号/丢失/恢复均有 banner；权限拒绝可去设置恢复；后台/来电自动暂停；杀进程可恢复草稿（≤24h 三按钮，>24h 仅保存/放弃且无「继续记录」）；单手可触达暂停/结束。
