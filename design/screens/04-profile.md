文件：`design/screens/04-profile.md` ｜ 原型：`design/prototype/index.html#profile`

### 4.1 状态与规格

| 状态 | 品牌卡 | 状态卡 |
|---|---|---|
| 未绑定 | 副标题「绑定后自动同步历史数据」；主按钮「授权 Coros 账号」52 `brand/600` | 不显示状态卡；下方「说明」置顶 |
| 授权中 | 主按钮变「授权中…」+ 16pt 指示器，禁用；副标题「正在打开 Coros 授权页面」 | 不显示 |
| 授权失败 | 顶部 `danger` banner 60：「授权失败：<原因>」+「重试」；主按钮恢复「重新授权」 | 不显示（从未连接） |
| 已连接 | 副标题「已连接 Coros 账号」；主按钮变 secondary「重新授权」（低频，折叠在更多） | 显示：状态行「已连接」+ success 点；上次同步时间；结果统计；按钮「立即同步」52 primary +「解除绑定」Text danger |
| 同步中 | 同已连接 | 状态行「同步中…」+ 16pt 指示器；进度文案「已获取 2/3 条」；按钮变「取消同步」Text；顶部线性进度条 2 高 |
| 同步成功 | 同已连接 | 顶部 `success` banner 44「同步完成：新增 3 条，更新 1 条」，3s 淡出；状态卡更新统计 |
| 部分成功 | 同已连接 | `warning` banner「2 条记录同步失败，可稍后重试」+「重试」 |
| 同步失败 | 同已连接 | `danger` banner「同步失败：<原因>」+「重试」；保留上次成功时间与统计 |
| 离线 | — | 顶部 warning banner「当前离线，无法同步」；「立即同步」禁用 |

- 授权失败原因文案分类：`网络连接失败，请检查网络` / `已取消授权` / `账号或密码错误` / `Coros 服务暂不可用，请稍后重试`；未知错误统一 `授权失败，请重试`。
- 同步失败原因：`网络连接失败` / `Coros 授权已过期，请重新授权` / `数据解析失败` / `服务暂不可用`。授权过期时状态卡主按钮变「重新授权」。
- 解除绑定：危险弹层（见 02 §8），确认后回未绑定态，保留已同步记录；toast「已解除绑定」。
- 底部说明固定 3 条，14/secondary，行距 8；文案不得承诺未实现能力（心率/睡眠等）。
- 隐私：授权页外链使用系统浏览器；不展示 access token；说明「数据只读」。

### 4.2 视觉

- 品牌卡 358×160，`surface`，`radius/lg`，内边距 20；Coros 图标用通用 `watch` 32 `brand/600`（不使用第三方商标 logo，避免授权问题）；标题 20/600「Coros」；副标题 14/secondary；按钮 52 宽撑满。
- 状态卡 358，`surface`，`radius/lg`，内边距 16；状态行 16/600 + 8pt 状态点；说明行 13/secondary；按钮区距 16。
- 说明区距卡 24，标题「说明」14/600。

## 5. 状态矩阵与规则

| 区块 | 加载 | 空 | 错误 | 离线 |
|---|---|---|---|---|
| 我的头部 | 骨架 | 未建档引导 | 保留缓存 + 重试 | banner |
| 数据概览 | 骨架 | 0 值（不隐藏） | `--` + 重试 | banner |
| 历史列表 | 3 行骨架 | 空态 | 错误态/缓存降级 | banner |
| Coros | 状态骨架 | 未绑定引导 | banner + 重试 | 禁用同步 |

- 所有「我的」数据在本地有缓存时优先展示缓存，网络失败只降级不白屏。
- 退出登录后回到登录页，清空本地 token 但保留未同步跑步草稿（下次登录提示恢复）。
- 不设计本迭代外的功能入口：无「AI 伙伴」「营养」「跑圈」「虚拟赛事」「会员」；「设置」内仅账号、隐私政策、关于、退出。

## 6. Flutter 实现要点

| 模块 | 建议 |
|---|---|
| 我的页 | `CustomScrollView` + `SliverAppBar.large`（大标题收起）；分组用 `SliverToBoxAdapter` |
| 头像 | 无头像时 `CircleAvatar` + 首字；预留 `avatarUrl` 字段但不做上传（不设计未排期功能） |
| 数据概览 | 从 `runRepository` 聚合：总里程、记录数、本周完成（训练 provider） |
| Coros 状态 | 复用 `coros_sync_provider` 的 `CorosSyncStateModel`（`lastStatus/lastSyncAt/lastImportedCount/lastError`）；授权中/同步中为本地瞬时状态 |
| 历史列表 | `ListView.builder` + 按 `startTime` 月分组；`RefreshIndicator`；分页 20 |
| 同步按钮 | 同步中禁用并显示进度；完成后 invalidate 历史与统计 |
| 解绑 | 清除 `flutter_secure_storage` 中 Coros token；保留 Isar 记录 |

验收：我的 7 种 Coros 状态全部可复现；历史列表空/错/载/离线齐全；用户信息缺失字段有兜底；无越界功能入口。
