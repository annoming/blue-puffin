## 全流程联调验证

### 流程1：新用户建档流程
1. 启动App → 登录/注册页面
2. 新用户注册（手机号或邮箱 + 密码）✅
3. 进入建档表单，填写完整信息✅
4. 提交建档 → 数据保存到Isar✅
5. 建档成功页面显示✅

### 流程2：今日训练 → 跑步关联流程
1. 首页 → 今日训练入口✅
2. 今日训练列表显示训练任务✅
3. 点击任务进入详情页，查看任务信息和跑前提示✅
4. 点击「开始跑步」跳转到跑步页，显示「计划关联跑步」标识✅
5. 开始跑步，记录轨迹和数据✅
6. 结束跑步，弹出完成提示，显示「跑步记录已关联训练任务并标记完成」✅
7. 返回首页，训练任务标记为已完成✅

### 流程3：自由跑步流程
1. 首页 → 开始跑步入口✅
2. 直接进入跑步页（无训练关联）✅
3. 开始/暂停/恢复/结束跑步✅
4. 跑步数据正常记录✅
