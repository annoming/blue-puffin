# Blue Puffin（步凡）- AI跑步助手

AI跑步助手「步凡」是一款面向马拉松爱好者的智能跑步应用。

## 技术栈
- Flutter 3.x (Dart 3.x)
- 状态管理：Riverpod
- 路由：go_router
- 网络：Dio
- 本地存储：Isar、SharedPreferences
- 定位：geolocator、flutter_background_service

## 快速开始
```bash
flutter pub get
flutter run
```

## 项目结构
见 `lib/` 目录结构，采用feature-first架构。
